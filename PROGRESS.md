## 4. BÀI HỌC KINH NGHIỆM (LESSONS LEARNED)
- **Flaky Tests:** Không dùng `Thread.Sleep`, luôn dùng `ITimeProvider`.
- **GDI Leak:** Luôn bọc P/Invoke trong `try/finally` hoặc `SafeHandle`.
- **Token Optimization:** Luôn dùng `Select-String` filter log. Mỗi task chạy trong 1 New Chat.
- **Lỗi Compile C#:** Tránh dùng anonymous type lẫn lộn với tuple (VD: `(double X, double Y)` vs `(int X, int Y)`). Khai báo tường minh.
- **FluentAssertions:** Dùng `.BeInRange(a,b)` thay vì `.BeBetween(a,b)`.
- **OCR native:** Engine gốc trả số có dấu cách (`6 253 000`); luôn lọc `[^\d]` trước khi parse.
- **WPF binding trong test:** control chưa vào cây hiển thị thì binding chưa chạy — sau khi gán `DataContext`/đổi thuộc tính phải đẩy dispatcher (`Invoke(() => {}, DispatcherPriority.DataBind)`) rồi mới đọc `TextBlock.Text`.
- **`StandardInputEncoding = Encoding.UTF8` ghi BOM** vào stdin của tiến trình con — autoit/shell coi 3 byte đó là lệnh đầu tiên. Luôn dùng `new UTF8Encoding(encoderShouldEmitUTF8Identifier: false)`.
- **Fake adb bằng batch:** file `.bat` phải **CRLF + ASCII** (LF-only làm cmd parse sai), và **không dùng pipeline `echo ... | findstr`** trong batch vì nó lấy mất stdin của `set /p`.
